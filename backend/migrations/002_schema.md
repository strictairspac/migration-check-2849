# Schema v2
Adds drill_packages/drill_aliases/drill_rows/drill_versions/drill_jobs for quality-drill sanitized copies built from completed runs. Each package owns an independent alias namespace (random alias_token + per-package sequence): the same commission keeps one alias across runs and appends within a package, different commissions never share an alias, and different recipient groups (separate packages) never share a namespace. drill_rows carries unique(package_id,run_id,ordinal) so append retries stay idempotent; introduced_version gates downloads to the last completed version while an append is still building. drill_versions freezes row_count/checksum evidence per issued version. Withdrawal only flips package status (downloads refuse withdrawn packages); reopening creates a new package with a fresh alias_token, never reusing old aliases.
